#### 📖 Описание и особенности
**el-Fihrist** — это портативный движок библиотеки навыков, фрагментов кода и памяти, разработанный для ИИ-агентов (Hermes Agent, Claude Desktop MCP, DeepSeek Harness, OpenCode, Codex).

* **Поисковая система BM25 на чистом Rust:** Высокоскоростная система релевантного поиска в памяти со сверткой турецких символов (например, `İ→i`, `I→ı`, `Ş→ş`).
* **Ядро Turso / SQLite:** Портативная база данных SQLite (`kutup_kutuphane.db`), содержащая более 140 внешних навыков и встроенные инструменты Rust.
* **Мульти-крейтовая архитектура:** Модульная структура Rust из двух крейтов: CLI (`ibnunnedim-cli`) и Core (`hermes-tools-core`).
* **Строгая проверка (Maşa Döngüsü):** Безопасный аудит кода и отчетов через шлюзы санитарной проверки D1-D3 и золотой шлюз R2.

##### 🧰 Доступные навыки и системные модули
БИБЛИОТЕКА `hermes-tools-core` предоставляет 10 модулей. Это Rust API; бинарный файл `ibnunnedim` не зависит от этого крейта — команды бинарного файла см. в разделе «Использование» ниже.
1. **citation:** Проверка цитат и составление отчетов для диссертаций и академических текстов через инфраструктуру Zopay (`verify_citations`).
2. **codebase:** Обобщение исходного кода, анализ содержимого файлов и выявление качества (`analyze_file_content`).
3. **docx:** Парсинг слоя MS Word XML и чтение в малом форм-факторе (`extract_paragraphs_from_xml`).
4. **extract:** Умный механизм извлечения чистого HTML и контента без шума (`html_ayikla`).
5. **masa_dongusu:** 4-шлюзовые механизмы проверки (D1, D2, D3, R2) и отчёт о переходах между шлюзами (`validate_masa_dongusu`).
6. **multilingual:** Стандартизированный механизм создания параллельных мультиязычных файлов README и контроль качества.
7. **router:** Маршрутизация подсетей агентов, кратчайший путь по алгоритму Дейкстры на графе и управление Edge/Route (`RouteResult`).
8. **rules_checker:** Продвинутый аудитор правил исходного кода Rust и стандартов качества (`check_rust_code_rules`).
9. **session:** Модуль поиска по подстроке для сеансов связи и данных памяти (`search_session`).
10. **skillopt:** Автономная эволюция навыков агентов; инфраструктура команд валидации Soft/Hard шлюзов с матрицей скоринга.

#### ⚙️ Требования и установка

##### Зависимости и пакеты (Crates)
* **Rust 1.63+** (Редакция 2021)
* Пакеты рабочего пространства (Workspace Crates): `ibnunnedim-cli`, `crates/hermes-tools-core`
* Системная база данных: `Turso SQLite 0.7.2` (`kutup_kutuphane.db`)

##### Сборка и запуск
```bash
# Релизная сборка рабочего пространства
cargo build --release --workspace

# Поиск навыков с помощью BM25
./target/release/ibnunnedim search "rust"

# Список навыков
./target/release/ibnunnedim list --kategori "software-development"

# Отправка оценки отчета (Tekmil)
./target/release/ibnunnedim tekmil --ajan "Kassam" --yetenek "zopay-rust-porting" --puan 100 --gerekce "Passed outer gauntlet"

# Запуск как stdio MCP-сервер (подключаются агенты/клиенты)
./target/release/ibnunnedim mcp
```

#### 🏗️ Инфраструктура и принцип работы
* **Индексация BM25:** Все навыки в базе данных считываются одним запросом и загружаются в BM25-индекс в памяти. Текст безопасно усекается с помощью стабильной для UTF-8 функции `kisalt`.
* **Интеграция с базой данных:** Устанавливает синхронизируемое (удаленное и локальное) zero-copy подключение к SQLite с помощью драйвера `turso::Builder::new_local`.
* **Утилиты уровней:** `tokio` (асинхронная среда выполнения), `clap` (парсер аргументов CLI), `serde_json` (протокол MCP и операции с манифестами).
