#### 📖 Описание и особенности
**el-Fihrist** — это портативный движок библиотеки навыков, фрагментов кода и памяти, разработанный для ИИ-агентов (Hermes Agent, Claude Desktop MCP, DeepSeek Harness, OpenCode, Codex).

* **Поисковая система BM25 на чистом Rust:** Высокоскоростная система релевантного поиска в памяти со сверткой турецких символов (например, `İ→i`, `I→ı`, `Ş→ş`).
* **Ядро Turso / SQLite:** Портативная база данных SQLite (`kutup_kutuphane.db`), содержащая более 140 внешних навыков и встроенные инструменты Rust.
* **Мульти-крейтовая архитектура:** Модульная структура Rust: CLI (`ibnunnedim-cli`) и девять библиотечных крейтов в `crates/` (перечислены ниже).

#### ⚙️ Требования и установка

##### Зависимости и пакеты (Crates)
* **Rust 1.63+** (Редакция 2021)
* Пакеты рабочего пространства (Workspace Crates): `ibnunnedim-cli`, `crates/fihrist-core`, `crates/fihrist-storage`, `crates/fihrist-gui`, `crates/fihrist-canli`, `crates/fihrist-nazar`, `crates/fihrist-kaynak`, `crates/fihrist-olcum`, `crates/fihrist-tema`, `crates/terim`
* Системная база данных: `Turso SQLite 0.8.2` (`kutup_kutuphane.db`)

##### Сборка и запуск
```bash
# Релизная сборка рабочего пространства
cargo build --release --workspace

# Поиск навыков с помощью BM25
./target/release/ibnunnedim search "rust"

# Список навыков
./target/release/ibnunnedim list --kategori "software-development"

# Отправка оценки отчета (Tekmil)
./target/release/ibnunnedim tekmil --ajan "Kassam" --yetenek "zopay-rust-porting" --puan 100 --gerekce "Passed outer gauntlet"

# Запуск как stdio MCP-сервер (подключаются агенты/клиенты)
./target/release/ibnunnedim mcp
```

#### 🏗️ Инфраструктура и принцип работы
* **Индексация BM25:** Все навыки в базе данных считываются одним запросом и загружаются в BM25-индекс в памяти. Текст безопасно усекается с помощью стабильной для UTF-8 функции `kisalt`.
* **Интеграция с базой данных:** Устанавливает синхронизируемое (удаленное и локальное) zero-copy подключение к SQLite с помощью драйвера `turso::Builder::new_local`.
* **Утилиты уровней:** `tokio` (асинхронная среда выполнения), `clap` (парсер аргументов CLI), `serde_json` (протокол MCP и операции с манифестами).
